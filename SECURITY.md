# Security Policy

## Supported versions

| Version | Supported |
|---|---|
| 1.0.x | ✅ |
| < 1.0 | ❌ |

## Reporting a vulnerability

Please **do not** open a public issue for security problems.
Use [GitHub private vulnerability reporting](https://github.com/ShardHazeGap/voxshift/security/advisories/new).

We aim to acknowledge reports within **48 hours** and ship a fix for confirmed critical issues within **7 days**.

## Official downloads only

VoxShift is distributed **only** through [GitHub Releases](https://github.com/ShardHazeGap/voxshift/releases), winget, Scoop, Homebrew and Flathub.
Every installer is code-signed and published with a SHA-256 checksum. Copies on other sites may contain malware.

## Privacy & abuse

VoxShift runs entirely on-device and has no telemetry. If you find a model in the Voice Hub that impersonates a real person or is used for fraud, report it via the in-app *Report* button or a private advisory.
